# g进数 使用文档

任意进制精确有理数，支持四则运算、进制转换、浮点展开、g-adic 展开与重构、连分数逼近。

```python
from math64 import g进数 as G
```

---

## 1. 构造

### 基本形式

```python
G(分子, 分母=1, 进制=None, 符号表=None)
```

分子、分母可以是 **十进制整数** 或 **当前进制下的字符串**（允许前导负号）。不传进制/符号表则使用类默认值（初始为十进制）。

```python
# 整数构造（默认十进制）
G(3, 4)          # → 3/4
G(-28, 1)        # → -28（分母为 1 时省略）
G(15, 25)        # → 3/5（自动约分）

# 字符串构造（进制内表示）
G("-A3", "14", 16, "0123456789ABCDEF")   # → A3/14（16进制），值 163/20

# 混合构造
G(45, "-103", 8, "01234567")             # 分子十进制 45，分母八进制 "-103"
```

### 进制与符号表

| 参数 | 说明 |
|------|------|
| `进制` | 2 到 `len(符号表)` 的整数 |
| `符号表` | 无重复、不含 `./\- ` 的字符串，默认 `0-9A-Z`（36字符） |

```python
G(7, "-be", 5, "abcde")   # 5进制，符号表 abcde → -bc/be（值 -7/9）
```

### 异常

| 条件 | 异常 |
|------|------|
| 分母 = 0 | `ZeroDivisionError("分母不能为0")` |
| 分子/分母非 int 或 str | `TypeError` |
| 进制或符号表不合法 | `TypeError` / `ValueError` |
| 字符串含超出进制范围的字符 | `ValueError` |

## 2. 只读属性

```python
a = G(7, "-be", 5, "abcde")   # 值 -7/9

a.进制       # 5
a.符号表     # "abcde"
a.分子值     # -7        ← 十进制整数
a.分母值     # 9         ← 十进制正整数
a.分子表示   # "-bc"     ← 当前进制下的字符串
a.分母表示   # "be"
```

---

## 3. 字符串表示

```python
str(a)       # "-bc/be"              — 分母为 1 时省略
repr(a)      # "十进制: -7/9, 当前进制为: 5, 表示: -bc/be"
```

---

## 4. 算术运算

所有运算返回 **新实例**（原实例不可变）。支持与 `int` 和 `g进数` 混合运算。不支持 `float`。

```python
a, b = G(1, 2), G(1, 3)

# 加减乘除
a + b        # 5/6
a + 3        # 7/2         — int 也可
5 + a        # 11/2        — 反向加法
a - b        # 1/6
a * b        # 1/6
a / b        # 3/2

# 取反、取绝对值
-a           # -1/2
abs(a)       # 1/2         — 保持进制
```

### 取模与整除（仅分母为 1 时可用）

```python
G(7, 1) % 3       # 1
G(10, 1) // G(3, 1)  # 3

G(3, 2) % 3       # ValueError("取模只允许分母值为1")
```

---

## 5. 幂运算

支持**整数指数**和**有理指数**（开方后再乘方）。

```python
G(2, 3) ** 2       # 4/9          — 正整数指数
G(3, 2) ** (-2)    # 4/9          — 负整数指数（先取倒）
G(16, 81) ** G(1, 2)  # 4/9       — 有理指数（平方根）
G(4, 9) ** G(-1, 2)   # 3/2       — 有理负指数

8 ** G(1, 3)        # 2            — int 底、有理指数

G(7, 1) ** G(1, 2)  # ValueError  — 7 不是完全平方数
```

**注意**：开方要求分子分母各自为完全 `n` 次方数，否则抛出 `ValueError`。

---

## 6. 比较运算

支持 `==` `!=` `<` `>` `<=` `>=`，可与 `int` 比较。

```python
G(1, 2) == G(2, 4)   # True   — 约分后相等
G(2, 1) == 2          # True   — 与 int 比较
G(1, 2) < G(3, 4)     # True   — 0.5 < 0.75
G(-1, 2) < G(-1, 3)   # True   — -0.5 < -0.333...

G(1, 2) == 0.5        # False  — float 直接返回 False（不抛异常）
G(1, 2) < 3.5         # TypeError — 不支持的类型
```

---

## 7. 类型转换

```python
float(G(3, 2))   # 1.5
int(G(3, 2))     # 1         — 向零取整
bool(G(0, 99))   # False     — 分子为 0 时为 False

hash(G(3, 2))    # hash((3, 2)) — 可放入 set/dict
```

---

## 8. 进制转换

```python
a = G(7, "-be", 5, "abcde")     # 5进制，值 -7/9

a.进制转换(10)                    # → -7/9（十进制表示）
a.进制转换(2)                     # → -111/1001（二进制表示）
a.进制转换(16, "0123456789ABCDEF") # → -7/9（十六进制，自定义符号表）
```

## 9. 类默认属性

```python
# 修改全局默认进制
G.修改类默认属性(进制=8)
G(10, 3)          # 使用八进制，不传进制参数

# 修改符号表
G.修改类默认属性(进制=3, 符号表="abc")
G(2, 1)           # 三进制，符号表 abc

# 恢复默认
G.修改类默认属性(进制=10, 符号表="0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ")
```

**注意**：只影响**之后创建**的实例，已有实例不受影响。非法参数不会修改状态（抛异常后保持原值）。

## 10. 浮点展开

返回当前进制下的小数表示，自动检测循环节。

```python
G(1, 2).浮点数()               # "0.5"
G(3, 4).浮点数()               # "0.75"
G(-3, 2).浮点数()              # "-1.5"
G(1, 3).浮点数()               # "0.(3)"       — 纯循环
G(1, 6).浮点数()               # "0.1(6)"      — 混循环
G(1, 7).浮点数(截断位数=5)      # "0.14285..."  — 未发现循环

# 自定义进制
G(1, 3, 2, "01").浮点数()       # "0.(01)"      — 二进制下的 1/3
G(1, 15, 16, "0123456789ABCDEF").浮点数()  # "0.(1)" — 十六进制
```

参数：`截断位数`（默认 30）— 达到该位数仍未发现循环则末尾加 `"..."`。

---

## 11. 有理数逼近

**静态方法**。从进制小数串反推最简有理数，支持三种格式。

```python
# 有限小数
G.有理数逼近("0.5")             # 1/2
G.有理数逼近("1.75")            # 7/4

# 纯循环 / 混循环
G.有理数逼近("0.(3)")           # 1/3
G.有理数逼近("0.1(6)")          # 1/6
G.有理数逼近("-1.2(3)")         # -37/30

# 截断小数（连分数逼近）
G.有理数逼近("0.142857...")     # 1/7
G.有理数逼近("3.141592653589...")  # π 的有理近似

# 自定义进制
G.有理数逼近("0.1", 2, "01")     # 1/2      — 二进制 0.1
G.有理数逼近("0.(01)", 2, "01")  # 1/3      — 二进制循环
```

截断格式使用连分数算法，在"最大跳跃"处截断以得到最佳有理逼近。位数不足时可能无法精确还原。

## 12. g-adic 展开与重构

### padic表示 — 有理数 → g-adic 展开

```python
G(7, 30, 10).padic表示()        # "(6).9"      — 10-adic 下 7/30
G(5, 1, 10).padic表示()         # "5"          — 整数
G(-7, 1, 10).padic表示()        # "(9)3"       — 负数（无符号，用补位）
G(1, 2, 10).padic表示()         # "0.5"        — 有限
G(1, 3, 10).padic表示()         # "(6)7"       — 纯循环
G(17, 31, 10).padic表示(截断位数=4)  # "...25807" — 截断不足

# 二进制
G(1, 3, 2, "01").padic表示()    # "(01)1"
G(1, 4, 2, "01").padic表示()    # "0.01"
```

**格式说明**：g-adic 数向**左**无限延伸，小数点右侧为有限位。括号标记向左的循环节，如 `"(6).9"` 表示 `...6666.9`。

### 有理数重构 — g-adic 展开 → 有理数

**静态方法**。是 `padic表示` 的逆操作。

```python
G.有理数重构("(6).9", 10)                  # 7/30
G.有理数重构("(3)", 10)                    # -1/3
G.有理数重构("...66.9", 10)                # 7/30     — 截断格式
G.有理数重构("(01)1", 2, "01")             # 1/3      — 二进制
G.有理数重构("...1011001111101", 2, "01")  # 17/37
G.有理数重构("0.5", 10)                    # 1/2      — 有限格式
G.有理数重构("5.0", 10)                    # 5/1      — 整数格式
```

### 往返一致性

```python
a = G(7, 30, 10)
G.有理数重构(a.padic表示(), 10) == a    # True — 展开再重构回到原值
```

截断格式的还原精度取决于有效位数：位数不足时结果不同。

## 13. g-adic 运算模式

g进数实例本身不支持 padic 层面的直接运算。正确的做法是三步：

```python
# 1. padic 字符串 → 有理数
r1 = G.有理数重构("(1)2", 进制=10)
r2 = G.有理数重构("(3204)4", 进制=10)

# 2. 在有理数域做运算（+ - * / ** 等）
result = r1 * r2

# 3. 有理数 → padic 字符串
padic_str = result.padic表示()

# 验证
assert G.有理数重构(padic_str, 进制=10) == result
```

这样做等价于 g-adic 上的精确运算，且利用了有理数域的所有功能。

---

## 14. 不可变性

所有运算返回新实例，原实例不会被修改。实例可安全用作 `dict` 的键或放入 `set`（实现了 `__hash__`）。

```python
a = G(1, 2)
b = a + 1      # a 不变，b 是新实例
s = {G(1,2), G(2,3)}   # 可用作集合元素
```

---

## 附：异常速查

| 异常 | 触发条件 |
|------|---------|
| `ZeroDivisionError` | 分母为 0、除以 0 |
| `TypeError` | 输入类型非 int/str、进制非 int、符号表非 str、不支持的运算类型 |
| `ValueError` | 符号表含非法字符/重复、进制不在 2..len(符号表)、字符串含非法字符/负号位置错误、非完全次方根、取模/整除时分母非 1、padic 截断位数不足 |
